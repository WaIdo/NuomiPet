# 糯米桌宠

一只住在桌面上的小团子，Windows 和 macOS 都能用。它会在屏幕底部走来走去，提醒喝水、休息和早睡，记得你们的纪念日，还会替你说悄悄话、递信。

![图标](build/icon.png)

## 功能

**宠物本身**
- 6 种小动物：猫猫、兔兔、小熊、狗狗、仓鼠、小鸡；11 种配色，9 种配饰（蝴蝶结、小花、小芽、小皇冠、派对帽、爱心发卡、草莓帽、圣诞帽、圆眼镜），4 种花纹，4 档大小。
- 会自己走来走去、发呆想事情、打哈欠、伸懒腰、转圈；眼睛会跟着鼠标转；离开电脑 5 分钟它会睡着（还会冒鼻涕泡），回来时会迎接你。
- 互动方式：
  - 鼠标在它身上来回划：摸摸头，会冒爱心
  - 单击：戳一戳（连续戳会被戳晕）
  - 双击：打开快捷面板（喂食、玩耍、番茄钟、心情、待办、小窝）
  - 右键：完整菜单
  - 按住拖动：把它拎起来，松手会掉回屏幕底部；甩出去会撞墙，摔重了会晕
- 12 种零食，每个物种都有最爱的食物；饱腹、心情和亲密度等级（Lv.1～Lv.10）。

**提醒和工具**
- 喝水、久坐起来动动、护眼、按时吃饭、早点睡；可以设置提醒只在某个时间段内出现。
- 自定义提醒：每天 / 工作日 / 周末 / 仅一次。
- 番茄钟：专注时宠物抱着小电脑陪着，结束后提醒休息。
- 待办清单，完成一件宠物会庆祝。
- 首页记着你们一起的回忆：摸摸、喂食、玩耍、喝水、专注、完成待办的累计次数。
- 天气（可选）：设置城市后，早上会播报天气，要下雨会提醒带伞。

**给她的部分**
- 纪念日：在一起第几天、整百天和周年、她的生日、自定义纪念日和倒数日。当天宠物会撒花庆祝，提前几天会预告。
- 信箱：在应用里写信，定好拆开的日子（比如她生日那天）。封好后没到日子谁都看不到正文；到了那天宠物会叼着信来找她。
- 悄悄话：你写的话会被宠物不定时说出来，可以署名「xxx让我偷偷告诉你：……」。
- 心情日记：每天晚上问她今天心情怎么样，小窝里有月历记录。
- 节日：元旦、情人节、女神节、白色情人节、520、儿童节、七夕、中秋、除夕、春节、元宵、端午、平安夜、圣诞、跨年都会送祝福（农历节日已算好到 2035 年）。她生日那天宠物会戴派对帽，圣诞节戴圣诞帽，情人节、520、七夕戴爱心发卡。
- 今日运势：右键菜单里点「今日运势」，每天一签。

**小窝的颜色**：樱花粉、蜜桃橘、奶油黄、薄荷绿、天空蓝、香芋紫六种，也可以选「跟宠物一样」（随宠物的配色变）。在「小窝 → 设置 → 小窝的颜色」里换，背景、按钮和宠物的对话气泡、快捷面板一起变。

「小窝」是设置窗口，从宠物右键菜单、快捷面板或托盘图标都能打开，里面有：首页（在一起天数、宠物状态、今日喝水/番茄/待办/心情、天气）、装扮、提醒、专注（番茄钟）、待办、纪念日、信箱、心情月历、悄悄话、设置（我们的资料、小窝的颜色、置顶、开机启动、声音、走动、重力、勿扰、天气城市、数据导入导出）。

## 写上你们自己的内容

所有内容都能在应用里设置，不需要改文件、也不需要重新打包：

- **资料**：第一次打开「小窝」时会弹出「我们来认识一下吧」，填宠物的名字、她的昵称、生日、在一起的日子和你的署名。之后在「小窝 → 设置 → 我们的资料」随时修改。宠物第一次见面后也会主动问她。
- **纪念日**：「小窝 → 纪念日」，可以加每年纪念、倒数日、累计天数。
- **悄悄话**：「小窝 → 悄悄话」，写下想让宠物不定时转告她的话。
- **信**：「小窝 → 信箱 → 写一封信」，写好标题、署名和正文，选「马上」或「到某一天」才能拆开。信封好之后，没到日子谁都看不到正文（写信的人也看不到）；写错了可以删掉重写，也可以改标题和拆开的日子。到了那天，宠物会叼着信去找她。
- **在自己电脑上写信**：在你的电脑上写好，「信箱 → 导出在这里写的信」存成文件，再到她的电脑上「导入信件」。导出的文件里正文不是明文，打开文件也不会直接看到内容。

### 可选：打包前预先写好

如果想让她第一次打开时就看到你写的内容，可以在打包前编辑项目根目录下的 `gift.config.json`：

| 字段 | 含义 | 例子 |
| --- | --- | --- |
| `petName` | 宠物的名字 | `"糯米"` |
| `nickname` | 宠物怎么称呼她 | `"宝贝"`、她的小名 |
| `sender` | 你的署名，悄悄话会说「xxx让我偷偷告诉你」；留空则不署名 | `"阿杰"` |
| `species` / `color` / `accessory` / `markings` / `size` | 初始形象，可选值见 `src/shared/catalog.json` | `"bunny"` / `"sakura"` / `"flower"` / `"none"` / `"m"` |
| `togetherSince` | 在一起的日子 | `"2023-05-20"` |
| `birthday` | 她的生日，可以只写月日 | `"1999-08-08"` 或 `"08-08"` |
| `anniversaries` | 其他纪念日 | `[{ "name": "第一次约会", "date": "2023-06-01", "kind": "yearly" }]` |
| `notes` | 悄悄话列表 | `["今天也要开心", "..."]` |
| `letters` | 信件 | 见下 |

`anniversaries` 的 `kind`：`yearly` 每年提醒，`countdown` 倒数日（一次性），`since` 累计天数（整百天时庆祝）。

信件示例（`id` 不能重复，`unlock` 留空表示马上能看，`body` 里用 `\n` 换行）：

```json
"letters": [
  {
    "id": "birthday-2026",
    "title": "生日快乐",
    "unlock": "2026-08-08",
    "from": "阿杰",
    "body": "第一行\n第二行……"
  }
]
```

默认带了一封宠物自我介绍的信（`id: "hello"`），第一次启动时会递给她。

## 打包

需要 Node.js 18 以上。

```bash
npm install
```

在国内下载 Electron 很慢，可以先设置镜像再安装和打包：

```bash
export ELECTRON_MIRROR="https://npmmirror.com/mirrors/electron/"
```

```bash
export ELECTRON_BUILDER_BINARIES_MIRROR="https://npmmirror.com/mirrors/electron-builder-binaries/"
```

如果 `npm install` 之后 `node_modules/electron/dist` 不存在（新版 npm 默认不执行安装脚本），手动下载一次：

```bash
node node_modules/electron/install.js
```

先在本机试运行：

```bash
npm start
```

打包（在 macOS 上可以同时打出 Mac 和 Windows 的包，不需要 Wine）：

```bash
npm run dist:mac
```

```bash
npm run dist:win
```

产物在 `dist/` 目录：

| 文件 | 用途 |
| --- | --- |
| `NuomiPet-1.0.0-mac-arm64.dmg` | Apple 芯片的 Mac（M1/M2/M3/M4…） |
| `NuomiPet-1.0.0-mac-x64.dmg` | Intel 芯片的 Mac |
| `NuomiPet-1.0.0-win-setup.exe` | Windows 安装版（推荐） |
| `NuomiPet-1.0.0-win-portable.exe` | Windows 免安装版，双击就能用 |

改了宠物形象的代码后想重新生成图标：`npm run icons`。

## 安装

**macOS**

1. 打开 dmg，把「糯米桌宠」拖进「应用程序」。
2. 第一次打开时系统会提示无法验证开发者（应用没有花钱买苹果的开发者签名）。打开「系统设置 → 隐私与安全性」，在页面下方点「仍要打开」。
3. 也可以在终端执行一次下面的命令，之后就能直接双击打开：

```bash
xattr -dr com.apple.quarantine /Applications/糯米桌宠.app
```

宠物出现在屏幕底部；菜单栏右上角有一个小猫头图标，点它可以打开菜单。

**Windows**

1. 运行 `NuomiPet-1.0.0-win-setup.exe` 安装（或者直接运行免安装版）。
2. 如果出现「Windows 已保护你的电脑」，点「更多信息 → 仍要运行」。
3. 右下角托盘区有一个粉色小猫图标（可能藏在 `^` 里），点它可以打开菜单。

## 使用小贴士

- `Ctrl + Alt + P`（Mac 上是 `⌘ + ⌥ + P`）：显示 / 隐藏宠物，全屏看视频时很方便。
- 宠物被藏起来后，点托盘图标选「叫它出来」，或者再打开一次应用。
- 「叫它过来」会让宠物从鼠标所在的屏幕上方掉下来，多个显示器时很好用。
- 右键菜单里可以关掉「自由走动」「声音」，打开「勿扰模式」：宠物不再闲聊，也不提醒喝水、久坐、护眼、吃饭、睡觉；自定义提醒、番茄钟、纪念日和信照常。
- 开机自动启动在小窝的「设置」页或托盘菜单里打开。

## 卸载

- macOS：先在托盘菜单里「退出」，再把「应用程序」里的「糯米桌宠」拖到废纸篓。
- Windows：「设置 → 应用」里找到「糯米桌宠」卸载；免安装版直接删掉 exe。

卸载不会删除数据（见下），重新安装后宠物还记得你们。

## 数据保存在哪

- macOS：`~/Library/Application Support/糯米桌宠/mochi-data.json`
- Windows：`%APPDATA%\糯米桌宠\mochi-data.json`

小窝「设置」页可以导出和导入备份。

## 项目结构

```
gift.config.json        送礼配置（名字、纪念日、悄悄话、信件）
src/main/               主进程：窗口、拖拽和下落物理、托盘、提醒调度、番茄钟、天气、数据存储
src/preload/preload.js  渲染进程可用的接口（window.mochi）
src/shared/             两边共用的数据：物种/配色/食物目录、台词、节日表、日期工具
src/renderer/shared/    宠物的 SVG 形象、表情和动画、音效
src/renderer/pet/       桌宠窗口：行为逻辑、气泡、特效、快捷面板
src/renderer/home/      小窝（设置窗口）
src/renderer/letter/    信件窗口
scripts/                图标生成、页面截图、主题配色生成（make-theme.py，改了粉色样式后重新运行）
dev/                    开发用的预览页、测试场景、小窝的模拟数据（mock-preload.js）
test/                   自动测试
```

运行测试（调度器的日期逻辑、番茄钟状态机）：

```bash
npm test
```

开发时可以用独立的数据目录运行，并执行测试场景脚本（会自动截图）：

```bash
SNAP_DIR=/tmp/snaps npx electron . --data-dir=/tmp/pet-data --dev-script=dev/scenarios/basic.js
```
